# Medusa's Memory Heist

**Medusa's Memory Heist** is an open-source educational game that makes agentic AI safety and security easier to explore, discuss, and teach.

## 1. Getting Started
- [Play Medusa's Memory Heist](https://microsoft.github.io/medusa/)
- [Explore the supporting site](https://microsoft.github.io/medusa/site/)

## 2. About the game and why we made it

Agentic AI systems can introduce new security risks, but learning how to identify and address those risks can feel complex. We created **Medusa's Memory Heist** to make these concepts approachable through short, interactive challenges.

The game gives players a friendly way to practice thinking like both a defender and an attacker. It is designed for workshops, events, team learning, and self-guided exploration.

## 3. What the game includes

The game includes five mini-games covering core AI security practices:

- **Threat modeling:** Identify what could go wrong before an incident happens.
- **Red teaming:** Explore how an attacker might misuse or manipulate a system.
- **Defense:** Choose safeguards that reduce risk.
- **Logging:** Decide what activity should be recorded so problems can be detected and investigated.
- **Incident response:** Practice responding when something goes wrong.

You can play the mini-games individually or use the full collection as a team learning experience.

## 4. Create your own educational game

This repository is also a starting point for building your own agentic AI educational experience. You can branch the code, replace the story and learning content, and adapt the game for your audience.

A simple way to begin:

1. **Create a branch** of this repository.
2. **Choose a learning goal** for your audience.
3. **Update the story, scenarios, questions, and resources.**
4. **Test the experience** with a few learners and improve it based on their feedback.
5. **Share what you create** so others can learn from it too.

Please review the repository's license and contribution guidance before publishing or distributing your version.
